## 金额独立复算

样本取自 Phase 1 的[真实结构脱敏夹具](../tests/fixtures/turn.jsonl)。SHA-256 为 `c8bef5a421173e73489058726f9bb28533c22e54a3829e743d0514228aeb9556`。两份独立设备授权各上传同一组三笔响应，最终对 114,148 Token 计价。下列价格仅用于验收。

| 计价类别 | 数量 | 测试单价（美元 / 百万 Token） | 应计美元 |
| --- | ---: | ---: | ---: |
| 普通输入 | 3,543 | 2.00 | 0.007086 |
| 缓存读 | 106,368 | 0.50 | 0.053184 |
| 缓存写 | 0 | 未提供 | 0 |
| 输出（含推理） | 4,237 | 8.00 | 0.033896 |
| 合计 | 114,148 | | **0.094166** |

在第二笔响应发生的毫秒切换输出价格，后续两笔使用新版。实时核算随之更新，已保存的原快照仍为 0.094166 美元。撤回两个设备对第一笔响应的来源后，实时明细剩余两笔。

固定测试账单为 100 元，官方实扣凭据的两个线程及未归属池数量为 2、1、1。分摊金额分别为 50、25、25 元。再以三等份分配 0.01 元，唯一余分按稳定键分配，各行之和精确等于账单实付。免费 Global Reset 增加一条零金额记录，付费重置单独保留 8.50 元实付，订阅账单金额保持 100 元。

## 证据范围

- 官方实扣和实付订阅账单通过手工凭据录入。真实账号缺少任务级官方实扣时，只能在覆盖充分、权重完整时给出 ESTIMATED 分摊。预置公开参考价仅覆盖 GPT-4.1 标准文本档位，其他模型、缺价类别及不适用的价格须另行核对。
- 账期静态快照与当前实时账本可以并存。处于进行中的账期会随迟到用量重新分摊。本地侧栏展示最近同步至当前账号的费用及截至时间。服务端无法观测一台断网电脑此刻的本地未传队列，完整性判断还依赖用户对已选来源的覆盖确认。
- 双设备用例使用同一台物理电脑上的独立设备身份和状态库。托盘本轮核对数据绑定、费用文字及宿主生命周期。两台物理 Windows 联测、Docker Compose 实际启动和 Phase 2 的 125% DPI 补验继续按负责人决定暂缓。

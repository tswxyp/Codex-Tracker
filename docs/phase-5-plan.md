# Phase 5 项目盈利管理实施计划
2026-11-19

| 顺序 | 模块 | 数据与验收依据 |
| --- | --- | --- |
| 1 | 项目档案与会话归属 | 沿用账号内 project、group、member 和同步修订。客户、合同、状态、起止日期留在服务端。通过稳定线程或运行会话 ID 关联，重名分别保存。 |
| 2 | 现金流水 | 独立 finance schema v1 保存带版本的项目档案、回款、额外 AI、人工、服务器及其他支出。付费重置直接引用 P4 原记录，外币按明确录入的实付折合人民币处理。 |
| 3 | 项目与账期报表 | 从 P4 复用分币后的人民币分摊与覆盖状态。按实际到账扣现金成本，单列 API 等效、未归属及待核算部分。并行活动区间按项目求并集。 |
| 4 | 查询与交付 | 从浏览器维护和修订，支持全程、单账期、项目排行、CSV 与 XLSX。服务端导出与页面复用同一份计算结果。 |
| 5 | 回归 | 临时 PostgreSQL 与 HTTPS 实测账号隔离、幂等与版本冲突、时间边界、亏损和零收入、未归属、免费与付费重置、P4 升级及浏览器导出。 |

金额报表使用人民币，合同余额按合同额减累计到账，支持部分回款。每千万或每亿 Token 的订阅均价仅在覆盖可确认时按实付和同期用量计算。项目成本优先沿用 P4 的 Credits 分摊。P2/P3 已登记的现场补验继续暂缓。

## 实际样本与准确率

直接读取本机 6 个 JSONL 和 22 个 Zstandard 文件，同时覆盖活动和归档目录。按大小和稳定性筛选，压缩档按路径等距抽样。独立验证使用 Python 读取 JSON，使用 Node.js 的 Zstandard 解码，逐字段比较最终 SQLite 账项。正式样本共 6,133 行，扫描前后所有文件 SHA-256 一致。首次导入 2,984 个规范事件与 2,984 条物理观测，其中 1,089 条保存了原始计量 JSON。第二次扫描更新文件 0 个、新增事件 0 个。

| 核对项 | 实测结果 | 分母 |
| --- | ---: | --- |
| 逐响应六字段完全相符 | **97 / 97，100%** | 在原始文件中独立识别到的唯一、无矛盾响应；数据库无额外响应账项 |
| 逐响应模型相符 | **97 / 97，100%** | 可用原始线程与轮次上下文核对的响应 |
| 旧格式线程六字段合计相符 | **19 / 19，100%** | 独立差分计算可核算、且有旧式账项的线程 |
| 逐响应精确快照配对 | **79 / 97，81.44%** | 有完整响应 ID 的记录中，同时匹配本次和累计向量的响应 |
| 数据库完整性 | integrity_check 为 ok，外键错误 0 | 完成真实导入后的整个交付库 |

97 条逐响应的原始向量合计为输入 7,148,861、输出 63,130、缓存读 6,545,152、缓存写 0、推理 16,007、总计 **7,211,991**。其余已核算账项来自 863 条旧式增量，合计 **66,333,221**。两组账项合计 **73,545,212**。缓存读与推理作为拆分展示，均未再次加入总数。样本中有 14 个子代理线程和 6 个带分叉来源的线程。

按证据拆分，这个总数包含 7,211,991 个逐响应观测 Token、7,518,825 个常规快照推导 Token，以及 **58,814,396 个归属待核实 Token**。最后一组来自 755 条具有继承关系的旧式增量。其算术与独立解析一致，但缺少逐响应身份，无法仅从当前样本完全证明归属。CLI 和 WPF 均把这部分列在“其中待核实”。同一时刻、向量相同且能追溯到祖先的旧快照会从子线程账本剔除；自动化测试覆盖父日志晚到后撤销子线程重复项。交付库重算后，账本、核对、时间区间、会话和质量提示与重新创建的样本库逐行一致。

992 个快照的核对结果为 79 个精确匹配、863 个验证增量、27 个重复累计、18 个未匹配、4 个期初基线未知、1 个差量未确认。18 条缺少精确快照的响应仍有独立 ID 和有效 `usage`，保留响应账项及质量提示。未匹配快照不额外入账。有 283 项已核算用量缺少可靠模型，保留在 `UNKNOWN` 模型桶中。

第一次选样时，有一个当前会话在核对期间继续追加，源哈希检查拒绝了该轮结果。正式样本排除了当天新建的明文会话并再次核验哈希。Phase 0 使用过有上限的文件前缀，本文使用完整的冻结文件，两次样本及分母不同。上述百分比描述账本对这批原始记录的复现程度。产品未取得官方完整账单或全部历史活动的人工标注，因此不能给出官方用量准确率或全机覆盖率。

| 验收场景 | 实际验证 |

| 1. 重复扫描 | 正常重扫、强制重读和投影重算后，事件数、账本总额和原始计量记录符合预期。 |

## 耗时口径与剩余问题

- **历史活跃时间只能给出有证据部分。** 本批各线程墙钟跨度之和为 1,394,344,550 毫秒，其中 1,374,397 毫秒有可采信的短模型工作区间，831,294,721 毫秒为已知暂停/本机睡眠，561,675,432 毫秒为未知。三项相加等于总历时。此处为逐线程求和，有并行关系的线程不能直接作为项目总耗时相加。
- **窗口与时间证据有边界。** 本阶段采用 60 秒保守上限，超出的整个模型条目留在未知时间；普通工具调用、网络等待和事件间隔均不直接计活跃。短模型条目表示客户端观测到的工作区间，无法精确测量服务端计算时间。本机可访问 108 条睡眠/唤醒区间。设备迁移、系统日志轮转或无权限时，睡眠证据可能缺失。
- **财务精度未参与测量。** 正式样本缓存写均为零；正值缓存写的代码行为有回归测试，仍缺少同条件的真实正值样本。模型、速度或旧计数基线缺证据时保留未知。该样本不验证官方 Credits、订阅费用或跨设备合并。
- **重放与规模。** 明文支持直接定位，压缩流中段续读需要重新解压前缀。文件截断、大小/时间变化及检查点摘要能识别常见轮替；任意改写大文件中部且伪装旧元数据时，需要显式重放或使用新库完整复核。本批未对整机十余 GiB 的所有历史档计时，Windows 10 尚未实机验证。

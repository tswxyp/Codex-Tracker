# Phase 2 分层窗口命中报告

2026-11-18，Windows 11 x64、96 DPI。交互对象为正式 Codex 左侧聊天列表，以及独立的 Windows 测试窗。分层窗同时设置 WS_EX_LAYERED、WS_EX_TRANSPARENT、WS_EX_NOACTIVATE 及 WS_EX_TOOLWINDOW。每个窗归属于当前 Codex 顶层 HWND。点击及滚轮由操作系统直接投递，悬停通过轮询屏幕指针与原生行边界触发。

| 验证 | 实测 |
| --- | --- |
| 原生标签 | 最大化样本中 6 个标签的中心点全部通过 WindowFromPoint 回到 Codex 窗口树。短标题展示精确数字或带 ≈ 的紧凑数字。 |
| 悬停详情 | 把指针停在已有标签的安全区域，出现 1 个详情窗。6 个标签加 1 个详情，**7/7** 中心点回到 Codex。详情显示输入、输出、缓存、模型、四类时间、可信度及待计算项。停在原生操作按钮上会收起详情。 |
| 行内操作按钮 | 对 17 个匹配行的 34 个原生操作矩形取中心点，**34/34** 命中 Codex。标签布局与按钮矩形分离。实机未触发会改动聊天状态的置顶或归档动作。 |
| 真实输入 | 在原生行标签区域点击后切换聊天。从标签上滚动时侧栏实际换行。受控窗口中，鼠标下方的原生 Button 在覆盖存在时收到 1 次 Click 及 1 次 +120 Wheel，焦点仍在原窗口。 |
| 窗口消息 | 实际创建的覆盖 HWND 四项样式齐全。WM_NCHITTEST 返回 HTTRANSPARENT，WM_MOUSEACTIVATE 返回 MA_NOACTIVATE。浅色与深色覆盖的点命中均通过。 |
| 失效处理 | 滚轮或按钮状态转换会撤销旧帧。按下鼠标拖动期间暂停绘制。窗口失焦、几何或 DPI 不一致、目录读取失败、匹配不足、过期帧会隐藏标签。重新取得有效帧后恢复。 |
| 空间限制 | 该布局下原生行约 324×30 物理像素，右端有两个约 20×20 的按钮。用原生字体测量标题并预留图标和操作空间。18 行中 17 行有统计，6 行在该帧内有空间显示数字，其余匹配行可用悬停详情。实际宽度随布局、标题和数字长度变化。 |

**边界。** 点命中覆盖采样位置；实际点击和滚轮覆盖上述动作。多屏混合 DPI、Windows 10、不同应用版本的命中仍缺实机数据。布局通过周期性 UIA 快照跟踪，界面持续动画或目录正在写入时允许短暂隐藏；本轮未测量每个滚动帧的视觉延迟。
